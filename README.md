# ☁️ AWS AI Quest — Juegos para el AIF-C01

Plataforma interactiva en español para pasar el **AWS Certified AI Practitioner** jugando.

## Juegos
- ⚔️ Quiz Battle (140+ preguntas, 5 dominios)
- 🔗 Match AWS (servicio → caso de uso)
- 🧩 Ordena la tubería (pipeline ML, FM, RAG, agentes)
- 🎯 Caza-Prompt (few-shot, CoT, jailbreak)
- 🧪 RAG Lab (vector DB + calculadora de tokens)
- 🤝 Dilemas responsables (D4)
- 🛡️ Guardián Cloud (D5)
- 🎓 Simulacro real: 65 preguntas, 90 min, 700/1000

## Correr
```bash
cd app
npm install
npm run dev
```
Abre http://localhost:5173

El progreso (XP, rachas, mejor marca) se guarda en `localStorage`.
